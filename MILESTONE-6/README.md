# PriceOptima – ML Dynamic Pricing System

## 🚀 Overview
PriceOptima is an AI-powered pricing optimization system that predicts demand and recommends optimal prices.

## 🧠 Features
- Demand Prediction
- Price Optimization
- Elasticity Analysis
- Real-time KPI Dashboard

## 🛠️ Tech Stack
- Frontend: React
- Backend: FastAPI
- ML: XGBoost (simulated)
- Deployment: Vercel + Render
